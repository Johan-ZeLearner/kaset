## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `NWListener` on `0.0.0.0:<ephemeral-port>` | The spike binds an HTTP server reachable by anything on the LAN for the duration of the test. Random port; killed when subcommand exits. |
| Inbound TCP from any LAN device | Any LAN device can `GET /spike-<uuid>.wav` and receive the test fixture. |
| Outbound SOAP `POST` to `http://<sonos-ip>:1400/...` | Standard SOAP control to user-supplied Sonos IP; no secrets in payload. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | I (Information Disclosure) | NWListener serving fixture to LAN | mitigate | (a) Bind to ephemeral port (not 8088 or any well-known port) so it isn't trivially discoverable. (b) Serve only the pre-recorded royalty-free fixture from PLAN 01 — never private user content. (c) Per-stream UUID in URL: `/spike-<uuid>.wav` — random path means random LAN devices can't guess the URL. (d) Listener is destroyed via `listener.cancel()` on subcommand exit (defer block). (e) Only honors GETs; ignores other methods. |
| T-03-02 | D (Denial of Service) | NWListener accepts unbounded connections | mitigate | Cap concurrent connections to 4 (`NWParameters.allowLocalEndpointReuse = false`; track active connections in an actor). Reject the 5th connection with HTTP/1.0 503. |
| T-03-03 | T (Tampering) | SOAP response parser (CurrentTransportState extract) | mitigate | Use plain string contains/regex per RESEARCH.md "Verified pattern: GetTransportInfo response parse" (`<CurrentTransportState>([^<]+)</CurrentTransportState>`). Cap response data size (already done in sendSonosSOAP — URLSession default is bounded). Tolerate malformed responses by returning nil and treating as poll failure (not crash). |
| T-03-04 | S (Spoofing) | Trusting that the IP we got from PLAN 02 is actually the user's Sonos | accept | The user supplies the IP as a CLI arg (or it comes from PLAN 02 discovery output the user pasted). Worst case: SOAP fails with HTTP error or timeout — surface error, exit 1, no escalation path. |
| T-03-05 | I (Information Disclosure) | stdout — printed Sonos IP and Mac LAN IP | mitigate | Same redaction policy as PLAN 02: stdout in developer terminal is fine. PLAN 06 redacts before committing REPORT.md. |

      ```swift
      func serveStaticAudioFile(
          path: URL,
          contentType: String,
          macIP: String,
          port: UInt16
      ) async throws -> (listener: NWListener, port: UInt16, sonosURIString: String, fileSuffix: String) {
          let nwPort: NWEndpoint.Port = port == 0 ? .any : NWEndpoint.Port(rawValue: port) ?? .any
          let listener = try NWListener(using: .tcp, on: nwPort)
          let fileBytes = try Data(contentsOf: path)
          let uuid = UUID().uuidString
          let suffix: String
          switch contentType {
          case "audio/wav": suffix = "wav"
          case "audio/aac": suffix = "aac"
          default: throw SonosSpikeError.invalidURL("unsupported contentType \(contentType)")
          }

          // Cap concurrent connections to 4 (T-03-02)
          let connCounter = ConnectionCounter()

          listener.newConnectionHandler = { connection in
              Task {
                  let allowed = await connCounter.tryAcquire(max: 4)
                  guard allowed else {
                      // Best-effort 503 then drop
                      let body = "HTTP/1.0 503 Service Unavailable\r\nConnection: close\r\n\r\n".data(using: .utf8) ?? Data()
                      connection.start(queue: .global())
                      connection.send(content: body, completion: .contentProcessed { _ in connection.cancel() })
                      return
                  }
                  connection.start(queue: .global())
                  connection.receive(minimumIncompleteLength: 1, maximumLength: 4096) { _, _, _, _ in
                      // Build response: HTTP/1.0 + Connection: close + NO Content-Length + NO Transfer-Encoding
                      let header = "HTTP/1.0 200 OK\r\nContent-Type: \(contentType)\r\nConnection: close\r\nCache-Control: no-cache\r\n\r\n"
                      guard let headerData = header.data(using: .utf8) else { return }
                      let response = headerData + fileBytes
                      connection.send(content: response, completion: .contentProcessed { _ in
                          connection.cancel()
                          Task { await connCounter.release() }
                      })
                  }
              }
          }

          // Wait for the listener to be ready and read back the actual port
          let actualPort = try await waitForListenerReady(listener)

          let sonosURIString = "x-rincon-mp3radio://\(macIP):\(actualPort)/spike-\(uuid).\(suffix)"
          return (listener, actualPort, sonosURIString, suffix)
      }

      actor ConnectionCounter {
          private var active = 0
          func tryAcquire(max: Int) -> Bool {
              if active < max { active += 1; return true }
              return false
          }
          func release() { active = max(0, active - 1) }
      }

      func waitForListenerReady(_ listener: NWListener) async throws -> UInt16 {
          try await withCheckedThrowingContinuation { (cont: CheckedContinuation<UInt16, Error>) in
              listener.stateUpdateHandler = { state in
                  switch state {
                  case .ready:
                      if let port = listener.port?.rawValue {
                          cont.resume(returning: port)
                      } else {
                          cont.resume(throwing: SonosSpikeError.malformedResponse)
                      }
                  case .failed(let error):
                      cont.resume(throwing: error)
                  case .cancelled:
                      cont.resume(throwing: SonosSpikeError.malformedResponse)
                  default:
                      break
                  }
              }
              listener.start(queue: .global())
          }
      }
      ```
