<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| LAN UDP multicast (send) → 239.255.255.250:1900 | Outbound multicast packets are broadcast to every device on the LAN. Anything on the LAN sees the M-SEARCH. |
| LAN UDP unicast (receive) → ephemeral port | Inbound HTTP/1.1 200 OK responses come from any UPnP device that wants to identify itself; payload is parsed by our code. |
| HTTP GET → discovered device's device_description.xml | Outbound TCP to a LAN address learned from the M-SEARCH response (potentially attacker-controlled if the LAN itself is hostile). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | I (Information Disclosure) | M-SEARCH packet payload | accept | M-SEARCH is a standard UPnP packet; reveals only that "this Mac is looking for Sonos zones." No PII, no credentials. UPnP is designed to be openly discoverable. |
| T-02-02 | T (Tampering) | Inbound SSDP response parser | mitigate | Cap maximum response size at 65535 bytes (UDP packet max) via `NWConnectionGroup.setReceiveHandler(maximumMessageSize: 65_535, rejectOversizedMessages: true)`. Reject any response without a parseable LOCATION header. Use guard-let / typed errors, no force-unwrapping of attacker-controlled fields. |
| T-02-03 | T (Tampering) + S (Spoofing) | device_description.xml fetch + parse | mitigate | Use `URLSession` with timeoutInterval: 3s for the GET. Parse with `XMLParser` (Foundation), not eval/regex against attacker XML. If parse fails, surface as malformedResponse and skip that device — never crash. Cap response size by setting `URLRequest.cachePolicy = .reloadIgnoringLocalCacheData` and rejecting bodies > 256 KB (Sonos descriptions are ~10 KB). |
| T-02-04 | I (Information Disclosure) | stdout — printed device IPs/USNs | mitigate | Print full IPs to stdout for spike convenience (developer terminal, not committed). The SPIKE-06 REPORT.md generation must redact LAN IPs (192.168.x.x → 192.168.x.REDACTED) before committing per CLAUDE.md no-secrets rule and RESEARCH.md "Project Constraints" T-section. PLAN 06 owns the redaction; THIS plan does not write the report. |
</threat_model>

      ```swift
      actor DiscoveryCollector {
          private(set) var devices: [String: DiscoveredSonosDevice] = [:]
          func add(_ device: DiscoveredSonosDevice) {
              if devices[device.usn] == nil { devices[device.usn] = device }
          }
          func snapshot() -> [DiscoveredSonosDevice] { Array(devices.values) }
      }

      func sendSSDPMSearchViaNWConnectionGroup(
          timeout: TimeInterval
      ) async throws -> [DiscoveredSonosDevice] {
          let multicast = try NWMulticastGroup(
              for: [.hostPort(host: "239.255.255.250", port: 1900)]
          )
          let group = NWConnectionGroup(with: multicast, using: .udp)
          let collector = DiscoveryCollector()

          let mSearch = "M-SEARCH * HTTP/1.1\r\nHOST: 239.255.255.250:1900\r\nMAN: \"ssdp:discover\"\r\nMX: 3\r\nST: urn:schemas-upnp-org:device:ZonePlayer:1\r\n\r\n"
          guard let mSearchData = mSearch.data(using: .utf8) else {
              throw SonosSpikeError.malformedResponse
          }

          group.setReceiveHandler(
              maximumMessageSize: 65_535,
              rejectOversizedMessages: true
          ) { _, content, _ in
              guard let content, let device = parseSSDPResponse(content) else { return }
              Task { await collector.add(device) }
          }

          group.start(queue: .global())
          group.send(content: mSearchData) { _ in }
          try await Task.sleep(for: .seconds(1))
          group.send(content: mSearchData) { _ in }
          try await Task.sleep(for: .seconds(1))
          group.send(content: mSearchData) { _ in }
          try await Task.sleep(for: .seconds(timeout))
          group.cancel()

          return await collector.snapshot()
      }
      ```

      ```swift
      func runSonosDiscover(args: [String]) async {
          var timeout: Int = 5
          var useBSDFallback = false
          var verbose = false
          var i = 0
          while i < args.count {
              switch args[i] {
              case "--timeout":
                  if i + 1 < args.count, let t = Int(args[i + 1]) {
                      timeout = max(3, min(30, t))
                      i += 2
                  } else {
                      print("❌ --timeout requires an integer 3..30")
                      exit(1)
                  }
              case "--bsd":
                  useBSDFallback = true
                  i += 1
              case "--verbose", "-v":
                  verbose = true
                  i += 1
              default:
                  i += 1
              }
          }
          print("🔍 SPIKE-04 — SSDP discovery on 239.255.255.250:1900")
          print("   Transport: \(useBSDFallback ? "BSD socket fallback" : "NWConnectionGroup")")
          print("   Timeout:   \(timeout)s")
          if let lanIP = detectMacLANIP() {
              print("   Mac LAN IP: \(lanIP)")
          }
          print("")

          do {
              var devices = useBSDFallback
                  ? try await sendSSDPMSearchViaBSDSocket(timeout: TimeInterval(timeout))
                  : try await sendSSDPMSearchViaNWConnectionGroup(timeout: TimeInterval(timeout))

              // Auto-fallback heuristic: if NWConnectionGroup returned 0 devices, try BSD
              // and exit with code 2 (go-with-workaround) if BSD finds them.
              var goWithWorkaround = false
              if devices.isEmpty, !useBSDFallback {
                  print("⚠️  NWConnectionGroup returned 0 devices — auto-trying BSD socket fallback...")
                  devices = try await sendSSDPMSearchViaBSDSocket(timeout: TimeInterval(timeout))
                  if !devices.isEmpty {
                      goWithWorkaround = true
                      print("⚠️  BSD socket found \(devices.count) device(s) — FB8461681 likely still bites macOS 26")
                  }
              }

              if devices.isEmpty {
                  print("❌ NO-GO: zero devices responded from either transport")
                  print("   Diagnostic: try `sudo tcpdump -i any port 1900` while re-running this command")
                  print("   to see whether M-SEARCH packets actually leave the Mac (RESEARCH.md Pitfall 5)")
                  exit(1)
              }

              // Fetch room names for each device (best-effort, parallel)
              await withTaskGroup(of: (Int, String?).self) { taskGroup in
                  for (idx, device) in devices.enumerated() {
                      taskGroup.addTask { (idx, await fetchRoomName(for: device)) }
                  }
                  for await (idx, name) in taskGroup {
                      devices[idx].roomName = name
                  }
              }

              print("✅ \(goWithWorkaround ? "GO-WITH-WORKAROUND" : "GO"): discovered \(devices.count) Sonos device(s):")
              for device in devices {
                  let name = device.roomName ?? "(roomName unknown)"
                  print("   • \(name) — \(device.ip):\(device.port)")
                  if verbose {
                      print("       USN:    \(device.usn)")
                      print("       SERVER: \(device.server)")
                      print("       LOCATION: \(device.location)")
                  }
              }
              exit(goWithWorkaround ? 2 : 0)
          } catch {
              print("❌ NO-GO: \(error)")
              exit(1)
          }
      }
      ```
